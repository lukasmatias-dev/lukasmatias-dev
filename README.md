## 🚀 Projetos em destaque

### 📌 [User API — Java e Spring Boot](https://github.com/lukasmatias-dev/user-api)

API REST para gerenciamento de usuários, desenvolvida com arquitetura em camadas e integração com banco de dados PostgreSQL.

**Tecnologias utilizadas:**
- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Flyway
- Maven
- Docker

**Funcionalidades:**
- Cadastro de usuários
- Consulta de usuários por ID e CPF
- Busca por nome
- Exclusão de usuários
- Persistência de dados em PostgreSQL
